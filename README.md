# Joint Genesis™ - Independent Review 2026

Landing page / advertorial de review independente para o produto **Joint Genesis™**.

## 🚀 Estrutura do Projeto
- `index.html`: Página principal com conteúdo, storytelling UGC (User-Generated Content), tabela de pontuação, ingredientes, comparativo de pacotes, FAQ e modais de compliance (Privacy Policy, Terms, About, Contact).

## 🛠️ Tecnologias Utilizadas
- HTML5 / CSS3 / JavaScript (Vanilla)
- [Bootstrap 5.3](https://getbootstrap.com/)
- [Font Awesome 6](https://fontawesome.com/)

## 📈 Áreas de Melhorias Recomendadas
1. **Design & UX/UI**: Tipografia moderna (Google Fonts como Inter/Outfit), estética premium, espaçamentos e micro-interações.
2. **Taxa de Conversão (CRO)**: Sticky CTAs em mobile, contadores de escassez/urgência elegantes, badges dinâmicos de garantia e social proof.
3. **Performance & SEO**: Otimização de imagens, WebP, lazy loading nativo, Schema.org (Product / Review schema structured data) e Open Graph tags.
4. **Rastreamento & Analytics**: Integração para pixels (Meta Pixel, Google Tag Manager, ClickBank hoplink tracking, postbacks).
